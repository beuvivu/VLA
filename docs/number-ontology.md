# Canonical number ontology

VLA separates deterministic number relations from statistical co-occurrence so
that Vietnamese lottery terminology does not create ambiguous data fields.

## Canonical production conventions

- **Lộn / đảo**: `AB -> BA`.
- **Bóng dương digit**: `0<->5`, `1<->6`, `2<->7`, `3<->8`, `4<->9`.
- **Bóng dương 2D**: apply the bóng-dương map to both digits.
- **Bộ / hệ seed label**: every label `00..99` can be used as a historical lookup
  label, but labels are not independent families.
- **Canonical bộ family**: quotient under digit-wise bóng dương plus lộn. The
  universe `00..99` partitions into exactly **15 unique families**: five families
  of 4 numbers and ten families of 8 numbers.
- **Cặp số (generic)**: any unordered pair of two 2D numbers. It does not imply a
  reverse, bóng or bộ relationship.
- **Cặp lộn**: the deterministic relation between `AB` and `BA`.
- **Same-draw co-occurrence pair**: a statistical observation that two distinct
  loto numbers appeared in the same draw. It is stored separately from cặp lộn.
- **Kép bằng**: `00,11,...,99`.
- **Kép lệch dương**: `05,50,16,61,27,72,38,83,49,94`.
- **Sát kép**: VLA's canonical linear-adjacency definition; the circular variant
  that also treats `09/90` as adjacent is exposed separately as research-only.

## Non-canonical folklore variants

Public references use conflicting definitions for terms such as **bóng âm** and
some **sát kép/kép âm** variants. VLA therefore does not silently map these terms
into production features. A disputed variant must have an explicit name and stay
research-only until a single documented definition is intentionally adopted.

## Data artifacts

`data/reference/` is regenerated by the production pipeline:

- `number_ontology_00_99.csv` — one row for each number `00..99`.
- `bo_seed_catalog_00_99.csv` — all 100 historical seed labels and their canonical
  family IDs.
- `bo_unique_families.csv` — exactly 15 unique canonical families.
- `manifest.json` — schema and terminology contract.

Pair artifacts carry a `pair_kind`, a canonical pair key, leading-zero-safe text
members, relationship flags and canonical bộ-family IDs.

## Excel integrity

Lottery prize codes in Excel are **text values**, not numeric cells with cosmetic
formats. Exact widths are mandatory:

- Đặc biệt / G1 / G2 / G3: **5 digits**
- G4 / G5: **4 digits**
- G6: **3 digits**
- G7: **2 digits**

Every export is reopened immediately and checked. CI additionally compares every
Excel prize cell back to `data/xsmb.csv`, including all 27 prize values in the
latest daily workbook. A missing leading zero, missing prize, wrong width, dirty
token, or wrong value fails the integrity gate.
