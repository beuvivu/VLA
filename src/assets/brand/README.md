# Lottery drum emblem

Created on 2026-10-19 with the built-in image generation tool for the requested VLA logo replacement. The mark has no wordmark or letters; its only text is the digits on the lottery balls.

Design prompt: a compact, stylized rotating lottery cage with sweeping indigo/violet ribs, numbered ivory and gold balls (6, 8, 9), a graceful cradle and a subtle motion stroke. Clean, premium contours, transparent background, legible as a small navigation emblem. No VLA lettering, slogan, watermark or background tile.

`lottery-drum-source.png` preserves the generated original. The web exports preserve transparency and are resized with Sharp: `lottery-drum.webp` is 192 × 192 (quality 90), `lottery-favicon.png` is 64 × 64, and `lottery-touch-icon.png` is 180 × 180. Only these three exports are copied into `docs/assets/` by `page_output.py`; their URLs are fingerprinted by `site_assets.py`.

The original reference icon collection in `../nexlink/` remains intact. Regenerate pages with `python scripts/ops/refresh_navigation.py`.
